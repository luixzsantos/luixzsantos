## About me

I am focused on developing modern web solutions and advanced system administration. I leverage an analytical and structured engineering mindset to map complex problems into efficient, clean, and scalable code.

My true passion in security lies within the **Red Team**: I love understanding how systems work internally, uncovering logic flaws, and breaking barriers in controlled environments. For me, mastering Linux and building complete web applications (from front to back) are the fundamental pillars for both creating incredible software and knowing exactly how to test its limits.

- 🔴 **Red Team:** Pentesting in controlled environments, reconnaissance, and web vulnerability exploitation (Burp Suite / Caido).
- 🌐 **Web Development:** Experience with modern architectures using JavaScript/TypeScript (Next.js, Node.js, Express.js).
- 🔬 **Malware & RE:** Reverse engineering and binary analysis (Assembly/C++).
- 🐍 **Backend:** JavaScript (TypeScript/Node/Express) and Python (Django/Flask/FastAPI).
- ⚙️ **Infra:** Docker, Linux, Bash/Shell scripting.
